# Πλήρης μεταφορά λειτουργιών Windows → Android

Καταγραφή: 7 Σεπτεμβρίου 2026. Βάση αναφοράς: ο τοπικός κώδικας του Mastixa Manager Windows (README v0.40.0-alpha.1), η λίστα 32 σελίδων του `app/main_window.py`, οι υλοποιήσεις των αντίστοιχων σελίδων και οι βοηθητικοί μηχανισμοί δεδομένων. Πρόκειται για έλεγχο κώδικα και σχεδιασμό μεταφοράς, όχι για πιστοποίηση ότι εκτελέστηκαν όλες οι λειτουργίες Windows.

Απαίτηση χρήστη: όλες οι λειτουργίες Windows να υπάρχουν και στο Android, με κατάλληλη εμφάνιση για κινητό. Οι σελίδες «Υπό κατασκευή» δεν θεωρούνται υλοποιημένες λειτουργίες. Η προηγούμενη εργασία Παραγωγού/Προϊόντων διακόπηκε πριν γίνουν αλλαγές.

Ολοκληρώθηκαν μηχανήματα/συντήρηση και τα δύο επόμενα εγκεκριμένα στάδια: τιμολόγια/OCR και κλείδωμα έτους/αναφορές. Επόμενο dashboard/ειδοποιήσεις/ημερολόγιο/αναζήτηση.

1. [x] **Διατήρηση σύνδεσης όταν η εφαρμογή πηγαίνει στο παρασκήνιο.** Αναφορά χρήστη: μετά από ελαχιστοποίηση/αλλαγή εφαρμογής (Alt+Tab) ζητείται ξανά login. Να διερευνηθεί η πραγματική διαδρομή επιστροφής (lifecycle, launcher, ενδεχόμενη επανεκκίνηση διεργασίας) και να προστεθεί χρονικό όριο από τη στιγμή μετάβασης στο παρασκήνιο. Η διάρκεια δεν ορίστηκε από τον χρήστη· να προβλεφθεί ρυθμιζόμενο όριο και να επιλεγεί εύλογη προεπιλογή κατά την υλοποίηση. Να τηρείται ιστορικό πλοήγησης, με συνεπή συμπεριφορά του κουμπιού Android και διατήρηση φίλτρων/θέσης όπου είναι δυνατό. Έλεγχος και για είσοδο από Γρήγορη πρόσβαση και συνδεδεμένες εγγραφές.

## Αρχική κατάσταση Android — ιστορική απογραφή

Λειτουργούν: τοπική σύνδεση με username/κωδικό, δημιουργία/επιλογή ανεξάρτητων προφίλ, αλλαγή κωδικού, αποσύνδεση, Ελληνικά/English, βασική αρχική με πλήθος/έκταση αγροτεμαχίων, προσαρμόσιμη γρήγορη πρόσβαση, CRUD αγροτεμαχίων, τοπικό backup/restore αγροτεμαχίων και ουράς αλλαγών, προσθετική εισαγωγή αγροτεμαχίων από Windows ZIP.

Δεν υπάρχει ακόμη πλήρης ισοδυναμία ρυθμίσεων/προφίλ με PC. Τα υπόλοιπα μητρώα, οικονομικά, αποθήκη, αναφορές, OCR και συγχρονισμός δεν είναι υλοποιημένα. Το τοπικό backup δεν περιλαμβάνει λογαριασμούς και κωδικούς. Η ουρά αλλαγών δεν αποτελεί λειτουργικό συγχρονισμό PC–Android.

## Ρυθμίσεις και λειτουργίες εκτός των βασικών σελίδων

- [ ] Ονομασία εκμετάλλευσης και επαναφορά προεπιλεγμένων ρυθμίσεων.

- [ ] Αρχειοθέτηση προφίλ με διατήρηση ανακτήσιμων δεδομένων, αντί για απλή καταστροφική διαγραφή.
- [ ] Εισαγωγή/εξαγωγή πλήρους προφίλ. Σαφής διάκριση από ZIP φορητών δεδομένων και backup αγροτεμαχίων.

- [ ] Άμεση αλλαγή γλώσσας μέσα στην εφαρμογή όπως στο PC· τώρα στο Android γίνεται μέσω επιστροφής στη σύνδεση.
- [ ] Φωτεινή/σκοτεινή εμφάνιση σε όλες τις οθόνες, φόρμες και διαλόγους.
- [ ] Αυτόματο ημερήσιο backup, αριθμός διατηρούμενων εκδόσεων, αντίγραφα πριν από restore, επιλογή θέσης/πρόσβαση σε αντίγραφα μέσω Android επιλογέα αρχείων.
- [ ] Backup όλων των μητρώων/κινήσεων και συνημμένων με έλεγχο έκδοσης/ακεραιότητας και ασφαλή επαναφορά ανά προφίλ.
- [ ] Διαγνωστικά και περιορισμένου μεγέθους log, δυνατότητα εξαγωγής του, πληροφορίες εκδόσεων και αδειών.
- [ ] Βοήθεια πεδίων, επιβεβαιώσεις επικίνδυνων αλλαγών και συμπεριφορά ακύρωσης σύμφωνα με τις αντίστοιχες ροές PC.

## Διασυνδέσεις που πρέπει να διατηρηθούν

1. Προϊόν ↔ αγροτεμάχιο ↔ στοιχεία καλλιέργειας. Διατήρηση ταυτότητας προϊόντος ακόμη και όταν αλλάξει όνομα ή απενεργοποιηθεί.
2. Παραγωγή ↔ προϊόν/αγροτεμάχιο ↔ διαθέσιμη ποσότητα προς πώληση.
3. Πώληση ↔ αγοραστής ↔ αυτόματο έσοδο. Ενημέρωση/διαγραφή χωρίς διπλή καταμέτρηση.
4. Παραλαβή αποθήκης ↔ προμηθευτής ↔ συνδεδεμένο έξοδο αγοράς.
5. Λίπανση/φυτοπροστασία ↔ κατανάλωση αποθήκης. Έλεγχος επάρκειας και αντιστροφή/διόρθωση κίνησης σε αλλαγές.
6. Συντήρηση μηχανήματος ↔ συνεργάτης ↔ συνδεδεμένο έξοδο.
7. Τιμολόγιο ↔ πρωτότυπο συνημμένο ↔ οικονομική εγγραφή. Η επανάληψη εισαγωγής/καταχώρισης δεν δημιουργεί διπλό έσοδο ή έξοδο.
8. Εργατικά/φυτεύσεις/καλλιεργητικές εργασίες ↔ ανάλυση κόστους αγροτεμαχίου. Αντιγραφή των κανόνων υπολογισμού PC χωρίς αυθαίρετη δημιουργία πρόσθετων εξόδων.
9. Κλείδωμα έτους εφαρμόζεται σε φόρμες, εισαγωγές και σχετικές μεταβολές δεδομένων· δεν είναι μόνο ένδειξη οθόνης.
10. Ιστορικό ενεργειών, έλεγχοι δεδομένων, αναφορές, ημερολόγιο και ειδοποιήσεις χρησιμοποιούν τις ίδιες εγγραφές και κανόνες.
