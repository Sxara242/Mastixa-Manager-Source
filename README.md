# Mastixa Manager v0.40.0-alpha.1

Αυτόνομη εφαρμογή Windows για την τοπική διαχείριση αγροτικής εκμετάλλευσης.

## Εφαρμογές και ανάπτυξη

Το repository περιλαμβάνει Windows Desktop (`main.py`, `app/`, Python/PySide6)
και Android (`android/`, native Java/SQLite). Η έκδοση Android είναι υπό ανάπτυξη:
διαθέτει τοπικά προφίλ, διαχείριση εκμετάλλευσης, προσθετική εισαγωγή ZIP Windows,
OCR, αναφορές, Dashboard, ειδοποιήσεις, τοπικούς χάρτες, GPS, σημεία και διαδρομές.
Υπάρχουν εξαγωγές συντεταγμένων και ελεγμένη υποδομή συγχρονισμού με τοπική ουρά
και διατήρηση συγκρούσεων. Η ζωντανή σύνδεση Supabase απαιτεί ακόμη ρύθμιση
λογαριασμού, dataset και πολιτικών πρόσβασης. Η πρόοδος καταγράφεται στο
[master ledger](docs/MASTER_PROGRESS.md).

Έλεγχος Windows από τη ρίζα: `python -m unittest discover -s tests -v`, αφού
εγκατασταθεί το `requirements.txt`. Τα τεστ χρησιμοποιούν προσωρινές βάσεις και
Qt offscreen. Για Android απαιτούνται JDK 17 ή 21 και Android SDK 36:
ορίστε `JAVA_HOME` και `ANDROID_HOME` και εκτελέστε από `android/`
`./gradlew assembleDebug lintDebug testDebugUnitTest`. Σε Windows χρησιμοποιήστε
`gradlew.bat`. Instrumentation σε emulator: `connectedChecksAndroidTest`· η
ξεχωριστή εφαρμογή `.checks` απομονώνει τα δοκιμαστικά δεδομένα.

Τα GitHub Actions ελέγχουν και τις δύο εφαρμογές χωρίς παραγωγικά κλειδιά και
χωρίς δημοσίευση APK. Δεν απαιτείται ρύθμιση Google/Supabase στην τρέχουσα έκδοση.
Μην προσθέτετε στο Git τοπικά SDK paths, κωδικούς υπογραφής, βάσεις ή αντίγραφα
δεδομένων. Αναλυτικές λειτουργίες: [Android README](android/README.md).

## Βασικές λειτουργίες

- Dashboard, ειδοποιήσεις, αναζήτηση και ενιαίο ημερολόγιο.
- Παραγωγός, αγροτεμάχια, προϊόντα και συνδέσεις προϊόντων–αγροτεμαχίων.
- Παραγωγή, πωλήσεις, έσοδα, έξοδα, αποθήκη, εργασίες και εξοπλισμός.
- Δήλωση καλλιέργειας, αναφορές, έλεγχος δεδομένων και κλείδωμα έτους.
- Φωτεινή και σκοτεινή λειτουργία σε ολόκληρο το περιβάλλον.
- Ελληνικό και αγγλικό περιβάλλον, με άμεση αλλαγή και επιλογή ανά προφίλ.
- Επιλογέας γλώσσας στην είσοδο προφίλ για πρόσβαση πριν από το login.
- Ανεξάρτητα προφίλ χρηστών, με ξεχωριστή βάση και backups ανά προφίλ.
- Προαιρετικό PIN, avatar/χρώμα, επιλογή προφίλ στην εκκίνηση και import/export.
- Αυτόματα και χειροκίνητα SQLite backups με έλεγχο εγκυρότητας.
- Offline προεπισκόπηση/εξαγωγή πακέτων, χωρίς δικτυακή αποστολή δεδομένων.
- Περιορισμένου μεγέθους τεχνικό log για ασφαλές debugging.

## Προαιρετικό OCR τιμολογίων

Η διαχείριση τιμολογίων λειτουργεί χωρίς OCR. Για αυτόματες προτάσεις
ημερομηνίας, προμηθευτή και ποσού απαιτείται εξωτερική εγκατάσταση του
Tesseract OCR. Το Tesseract δεν περιλαμβάνεται στην εφαρμογή ούτε εγκαθίσταται
από το `requirements.txt`. Η εφαρμογή το εντοπίζει από το `PATH` ή από τον
τυπικό φάκελο `C:\Program Files\Tesseract-OCR\`.

## Γλώσσες

Η γλώσσα αποθηκεύεται ξεχωριστά για κάθε προφίλ και αλλάζει χωρίς
επανεκκίνηση. Τα language packs βρίσκονται στο `app/locales/`. Νέα γλώσσα
προστίθεται ως JSON pack με μοναδικό κωδικό και μεταφράσεις· αν λείπει κάποια
μετάφραση, η εφαρμογή επιστρέφει με ασφάλεια στο ελληνικό αρχικό κείμενο.

## Εκτέλεση σε Windows

1. Εγκατάστησε Python 3.12 ή νεότερη έκδοση.
2. Κάνε διπλό κλικ στο `run.bat`.
3. Την πρώτη φορά εγκαθίστανται οι εξαρτήσεις του `requirements.txt`.

Σε υπάρχον περιβάλλον ανάπτυξης, μετά από αναβάθμιση του κώδικα εκτελέστε
`.\.venv\Scripts\python.exe -m pip install -r requirements.txt`.

## Χάρτες, GPS και εξαγωγές συντεταγμένων

Από τα Αγροτεμάχια ανοίγει χάρτης ορίων και εξαγωγή ενός, επιλεγμένων ή όλων
των αγροτεμαχίων που διαθέτουν γεωμετρία: CSV, XLSX, PDF, GeoJSON και KML.
Η αρχική γεωμετρία και το δηλωμένο CRS διατηρούνται. GeoJSON/KML εξάγονται
σε WGS84· οι πίνακες επιτρέπουν WGS84 ή το πραγματικό CRS πηγής.

Η τοπική απεικόνιση λειτουργεί χωρίς δίκτυο. Το OpenStreetMap ενεργοποιείται
προαιρετικά και ζητά μόνο τα ορατά πλακίδια, με αναφορά προέλευσης και cache.
Το Android καταγράφει GPS μόνο με ρητή ενέργεια και παύει τη διαδρομή όταν η
οθόνη χάρτη περάσει στο παρασκήνιο. Τα σημεία και οι διαδρομές αποθηκεύονται
στη βάση του προφίλ. Δεν έχει ενεργοποιηθεί μαζική λήψη offline χαρτών.

Η δημοσιευμένη υπηρεσία Κτηματολογίου δεν έδωσε επαληθεύσιμο schema στο
περιβάλλον ελέγχου· δεν παρουσιάζεται επιτυχής αναζήτηση γεωμετρίας με ΚΑΕΚ.
Google/Sentinel και live Supabase απαιτούν εξωτερική ρύθμιση.
Δείτε [GIS](docs/GIS_PHASE3_STATUS.md), [CRS](docs/CRS_VERIFICATION.md) και
[συγχρονισμό](docs/GIS_SYNC_VERIFICATION.md) για ακριβείς ελέγχους και περιορισμούς.

## Windows installer

Το επίσημο installer εγκαθιστά την εφαρμογή ανά χρήστη, χωρίς δικαιώματα
διαχειριστή. Τα προσωπικά δεδομένα δεν ενσωματώνονται στο installer και η
εγκατεστημένη εφαρμογή τα αποθηκεύει στο
`%LOCALAPPDATA%\MastixaManager\`. Ο φάκελος αυτός παραμένει ασφαλής σε update
ή απεγκατάσταση.

Για αναπαραγώγιμο release build απαιτούνται τα build-only εργαλεία του
`requirements-build.txt` και το Inno Setup 6.7.3. Από PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\packaging\build_release.ps1
```

Το τελικό αρχείο και το SHA-256 checksum δημιουργούνται στο
`dist\installer\`.

## Ιδιωτικότητα δεδομένων

Η εφαρμογή λειτουργεί τοπικά. Οι βάσεις, τα προφίλ, τα PIN, τα backups και οι
εξαγωγές αποθηκεύονται στους ignored φακέλους `data/` και `backups/` και δεν
πρέπει να προστίθενται στο Git.

Κύρια βάση παλιού/προεπιλεγμένου προφίλ: `data/mastixa_manager.db`

Νέα προφίλ: `data/profiles/<profile-id>/`

Αντίγραφα ασφαλείας: `backups/` και ο φάκελος κάθε προφίλ.

Τεχνικά logs: `data/logs/` (έως 1 MB ανά αρχείο και 5 παλιές εκδόσεις).
