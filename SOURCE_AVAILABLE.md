## Publication model

The intended public repository is source-only and should have a clean snapshot history rather than exposing the private development history. Windows installers and Android APKs are not intended to be committed to that public source repository.

Before public publication, first-party/third-party scope and asset provenance should be checked so that material with unconfirmed redistribution rights is not accidentally presented as PolyForm-licensed first-party content.

Binary distribution has additional third-party obligations and is a separate release-readiness question; a source-available repository does not automatically clear those obligations.
